The Java library uses Apache POI internally to convert a `Workbook` bean into a native Excel file. The entry point is the static method `WorkbookUtil.toExcel(Workbook workbook)`, which iterates over every `Sheet` and `Block` in the workbook and produces an `XSSFWorkbook` — Apache POI's in-memory representation of an `.xlsx` file. You can then write that object to a file, a byte array, or any `OutputStream`.

## Export to XLSX

```java
import in.org.quicko.sheet.beans.Workbook;
import in.org.quicko.sheet.beans.Sheet;
import in.org.quicko.sheet.beans.Table;
import in.org.quicko.sheet.utils.WorkbookUtil;
import org.apache.poi.xssf.usermodel.XSSFWorkbook;
import org.json.JSONArray;
import java.io.FileOutputStream;
import java.util.List;

// Build a workbook with one table
Table payments = new Table();
payments.setName("payments");
payments.setHeader(new JSONArray(List.of("id", "customer", "amount")));
payments.addRow(new JSONArray(List.of(1001, "Acme Corp", 5400.00)));
payments.addRow(new JSONArray(List.of(1002, "Globex",    1200.50)));

Sheet sheet = new Sheet();
sheet.setName("Q1");
sheet.addBlock(payments);

Workbook workbook = new Workbook();
workbook.addSheet(sheet);

// Convert to XSSFWorkbook and write to disk
XSSFWorkbook excel = WorkbookUtil.toExcel(workbook);

try (FileOutputStream fos = new FileOutputStream("report.xlsx")) {
    excel.write(fos);
}
excel.close();
```

`WorkbookUtil.toExcel` throws `java.io.IOException` so callers must handle or declare it. Always close the `XSSFWorkbook` after writing to release the underlying file handles held by Apache POI.

## How blocks are exported

Each `Sheet` becomes a tab in the Excel file named after `sheet.getName()`. Within the tab, blocks are laid out top-to-bottom in the order they were added.

### Table blocks

For each `Table`:

1. **Title row** — the table's name is written into a merged cell spanning all header columns (centered horizontally and vertically).
2. **Blank row** — one empty row separates the title from the header.
3. **Header row** — one row containing each column name from `table.getHeader()`.
4. **Data rows** — one row per entry in `table.getRows()`, with each cell populated from the inner `JSONArray`.
5. **Auto-sized columns** — `XSSFSheet.autoSizeColumn` is called for every column to fit content width.

### List blocks

For each `List`:

1. **Title row** — the list's name is written into a merged cell spanning two columns (centered horizontally and vertically).
2. **Blank row** — one empty row separates the title from the data.
3. **Key/value rows** — one row per `Item`: column A holds the key, column B holds the value.
4. **Auto-sized columns** — both columns are auto-sized.

## Sheet naming

Excel sheet tab names are taken directly from `sheet.getName()`:

```java
Sheet sheet = new Sheet();
sheet.setName("Q1 Payments"); // becomes the Excel tab label
```

<Note>
Excel enforces a **31-character limit** on sheet tab names. If `sheet.getName()` is longer than 31 characters, Apache POI will throw an `IllegalArgumentException` at export time. Keep sheet names short and avoid special characters (`\ / ? * [ ]`) that are also forbidden by Excel.
</Note>

## Column type handling

`WorkbookUtil.toExcel` inspects each cell value's runtime type when writing data rows from a `Table` and item values from a `List`, and calls the appropriate Apache POI setter:

| Java type | POI method called |
|---|---|
| `String` | `setCellValue(String)` |
| `BigDecimal` | `setCellValue(bigDecimal.doubleValue())` |
| `Integer` | `setCellValue(int)` |
| `Double` | `setCellValue(double)` |
| `Long` | `setCellValue(long)` |
| `Boolean` | `setCellValue(boolean)` |
| `null` | creates an empty cell |
| Any other type | `setCellValue(value.toString())` |

Values that are `null` or whose `toString()` equals `"null"` produce blank cells with no content.

## XLSX import

XLSX import (reading an `.xlsx` file back into a `Workbook` bean) is **not supported in the Java library**. That capability is provided by the Node.js library. For JSON round-trips in Java, use `JsonMapper`:

```java
import in.org.quicko.sheet.mapper.JsonMapper;

JsonMapper mapper = new JsonMapper();

// Serialize to JSON string
String json = mapper.writeValueAsString(workbook);

// Deserialize back to a Workbook
Workbook restored = mapper.readValue(json, Workbook.class);
```
