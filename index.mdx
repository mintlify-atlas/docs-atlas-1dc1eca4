Sheet JSON gives you a structured, language-agnostic way to represent spreadsheet workbooks as JSON. A workbook holds named sheets, each sheet holds typed blocks — either columnar `Table` blocks or key-value `List` blocks — and the whole structure serializes to a compact JSON format that any system can read or write. Libraries for Java and Node.js let you build, query, and convert workbooks in code, while CLI generators produce typed classes from JSON Schema so you never have to write boilerplate by hand.

## How It Works

<Steps>
  <Step title="Define your schema">
    Describe your workbook structure — sheets, tables, and lists — in a JSON Schema file, or generate one automatically from an existing Excel file or JSON workbook using the CLI.
  </Step>
  <Step title="Generate typed classes">
    Run `schema-to-objects` (Node.js) or the `schema-to-pojo` Maven goal (Java) to produce typed classes for your workbook, sheets, tables, rows, and lists. Import them directly in your application code.
  </Step>
  <Step title="Build and manipulate workbooks">
    Use the generated classes — or the base `Workbook`, `Sheet`, `Table`, and `List` classes directly — to build workbook data structures, add rows, look up values by name, and attach metadata.
  </Step>
  <Step title="Serialize and transport">
    Convert any workbook instance to portable JSON with `instanceToPlain` (Node.js) or `JsonMapper` (Java), or round-trip to `.xlsx` for spreadsheet-based workflows.
  </Step>
</Steps>

## Packages at a Glance

| Package | Language | Purpose |
|---|---|---|
| `@org-quicko/sheet` | Node.js / TypeScript | Core library — `Workbook`, `Sheet`, `Table`, `List`, XLSX I/O |
| `@org-quicko/sheet-generator` | Node.js / TypeScript | CLI — generate TypeScript classes from JSON Schema |
| `in.org.quicko.sheet:core` | Java | Core library — beans, Jackson serialization, XLSX I/O |
| `in.org.quicko.sheet:generator` | Java (Maven plugin) | Maven goal — generate Java POJOs from JSON Schema |

<Note>
  All packages are open source. The Node.js library requires Node.js ≥ 8.0.0. The Java library targets Java 25 (compiler release 25) and uses Apache POI for XLSX support.
</Note>
