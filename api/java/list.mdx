## Overview

`List` is a concrete [`Block`](/api/java/sheet) subtype that stores an ordered collection of key-value [`Item`](/api/java/item) pairs. It is the Sheet JSON equivalent of a properties or metadata block. Nine typed `addItem` overloads cover all common Java numeric, boolean, and string types.

**Package:** `in.org.quicko.sheet.beans`

**Extends:** `Block` → `BaseObject`

**Implements:** `java.io.Serializable`

```java
import in.org.quicko.sheet.beans.List;
import in.org.quicko.sheet.beans.Item;
```

<Note>`in.org.quicko.sheet.beans.List` shadows `java.util.List`. Use fully qualified names or import carefully when both are needed in the same compilation unit.</Note>

## Jackson annotations

| Annotation | Value | Effect |
|---|---|---|
| `@JsonTypeName` | `"list"` | Sets the JSON `name` discriminator field to `list` |
| `@JsonIgnoreProperties` | `ignoreUnknown = true` | Unknown JSON fields are silently ignored during deserialization |
| `@JsonTypeInfo` | `use = Id.NAME`, `include = AS.EXISTING_PROPERTY`, `property = "name"`, `visible = true` | Polymorphic type resolved from the existing `name` property |

The items collection is serialized under the JSON key `"items"` via `@JsonProperty("items")`.

## Constructor

### `List()`

```java
public List()
```

Default no-argument constructor. Initialises the `name` field to `"list"` via the parent `Block` constructor. The internal items `ArrayList` is lazily created on first access.

## Methods

### `getItems()`

```java
public java.util.List<Item> getItems()
```

Returns all items in insertion order. If the internal list has not been initialised, an empty `ArrayList` is created and returned.

**Returns:** `java.util.List<Item>` — the ordered items list, never `null`.

---

### `getItem(String key)`

```java
public Item getItem(String key)
```

Performs a case-insensitive linear search for an item by key.

**Parameters:**

| Name | Type | Description |
|---|---|---|
| `key` | `String` | The key to search for (case-insensitive) |

**Returns:** `Item` — the first matching item, or `null` if not found.

### `getItem(int index)`


**Parameters:**

| Name | Type | Description |
|---|---|---|
| `index` | `int` | Zero-based position in the items list |

**Returns:** `Item` — the item at that position, or `null` if `index` is out of range.

### `replaceItem(Item item)`

```java
public void replaceItem(Item item)
```

Finds the first item whose key matches `item.getKey()` (case-insensitive) and replaces it in-place.

**Parameters:**

| Name | Type | Description |
|---|---|---|
| `item` | `Item` | The replacement item; its `key` determines which existing item is replaced |

If no item with a matching key is found, the method returns without making changes.

## Code example

```java
import in.org.quicko.sheet.beans.Workbook;
import in.org.quicko.sheet.beans.Sheet;
import in.org.quicko.sheet.beans.List;
import in.org.quicko.sheet.beans.Item;
import in.org.quicko.sheet.mapper.JsonMapper;
import java.math.BigDecimal;

// Build a list block
List config = new List();
config.setName("AppConfig");

// Typed convenience overloads
config.addItem("appName",    "MyApp");
config.addItem("version",    "3.0.1");
config.addItem("maxRetries", 5);
config.addItem("timeout",    30.0);
config.addItem("enabled",    true);
config.addItem("threshold",  new BigDecimal("0.95"));

System.out.println("Item count: " + config.size()); // 6

// Key-based lookup
Item item = config.getItem("appName");
System.out.println(item.getStringValue()); // MyApp

// Index-based lookup
Item second = config.getItem(1);
System.out.println(second.getKey()); // version

// Replace by key
config.replaceItem(new Item("timeout", 60.0));

// Remove by key
config.removeItem("enabled");
System.out.println("Item count after removal: " + config.size()); // 5

// Serialize the list inside a workbook
Sheet sheet = new Sheet();
sheet.setName("Settings");
sheet.addBlock(config);

Workbook workbook = new Workbook();
workbook.addSheet(sheet);

JsonMapper mapper = new JsonMapper();
System.out.println(mapper.writeValueAsString(workbook));
```
